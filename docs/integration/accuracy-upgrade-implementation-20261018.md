## Implemented

- Native-frame decoding streams every source frame to optional RF-DETR/ByteTrack while retaining bounded original samples at 5 fps for verification. Cancellation, missing timestamps and cache limits fail explicitly instead of returning a truncated clean result.
- RF-DETR and local RTMPose adapters verify artifact hashes, versions, class mappings and gate metadata. Model absence or inference failure never becomes an empty successful detection. The optional GPU worker image/Compose overlay is available but unbuilt.
- Persistent desk objects and key-after-departure candidates have temporal checks. Missing ID/authenticity/recount actions and partial handovers need explicit tracked action and visibility evidence; absent detections do not supply it. Specialist proposals always require VLM confirmation. Original before/after key crops are included.
- Promotion binds the checkpoint, class map, detection thresholds, evaluation data, video-type/time results and analyzer decision policy. A class-only gate cannot enable violation types. Candidate-only evaluation is isolated from production activation.
- COCO preparation, RF-DETR fitting, heldout evaluation, full-video type gates and local SQLite MLflow export have executable commands. Crop QA LoRA supports the exact Qwen3-VL-30B-A3B MoE. The optional tracked-object Transformer has masked features and a separate training/runtime contract.
- Regression evaluation counts processing failures as failures, requires complete clip inventories, detects group/derivative leakage and rejects clean-clip false alarms. Public API load testing includes upload, queue, polling and response validation. CI separates synthetic software checks from real private model inference.
- Bootstrap pins model revisions, checks GPU/container/model access, preserves credentials and binding, fails on readiness timeout, enables prefix caching and limits the singleton worker to four jobs.
