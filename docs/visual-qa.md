## Проверка собранного UI

Статус: **PASS для просмотренных синтетических экранов**. A19 просмотрел восемь локальных скриншотов A16: desktop 1440px, узкий экран 360px и окно полного кадра. Использованы только искусственная тестовая видеотаблица и JPEG с меткой SYNTHETIC. Внешний вид проверен просмотром файлов; общий браузер/ПК не использовался.

Результат браузерной проверки A16: **7/7, 14.359s, 0 unexpected, 0 flaky** в `web/qa/results.json`; исходные сценарии — `web/qa/reviewer.spec.ts`. Проверены HTTP-заголовок и multipart-форма, ввод ключа без потери фокуса, выбор двух отдельных событий, переход к 7.2s, увеличение кадра, клавиатурная ловушка/возврат фокуса, normal/failed/processing, 360px без горизонтального переполнения, неверный файл, потеря связи и восстановление после неизвестного задания. Запросы перехватываются синтетическими ответами Playwright: это проверка frontend, не доказательство работы реального backend или модели.

В финальном прогоне отдельно подтверждена загрузка Open Sans через `document.fonts.load`; все восемь актуальных скриншотов повторно просмотрены с локальным шрифтом. A16 исправил ограничение Vite для sibling-папки `brand/`, оставив разрешенными только `web/` и `brand/`. Папка исходных частных видео не включена в этот allowlist. Тестовый Vite запускается и завершается самим harness; публичное развертывание этим не проверялось.

### Найдено в исходном CSS до рендера

В начальной версии `web/src/styles.css` обнаружены мелкие размеры: метка раздела 7px, время кадра 8px, текст правила 9px, наблюдение 11px. A16 получил запрос увеличить рабочий текст до 15–16px, время/подписи/правила до 13–14px и проверить мобильные переопределения. Это замечание о читаемости, не утверждение о нормативном минимальном размере WCAG. Повторное чтение исходников подтвердило увеличение размеров и более темный вторичный текст; финальная оценка выполняется по рендеру.

Также по фактическим значениям начального CSS рассчитаны пары ниже. Все они ниже принятой цели 4.5:1 для обычного текста. A16 получил точные селекторы и рекомендацию использовать `--forte-muted`. Исправление этих шести значений на `#5E5660` подтверждено в исходниках. Предложенные токены сами по себе ошибки в другом CSS не исправляют; требуется проверка наследования/состояний в браузере.

Отдельно обнаружено, что эффект установки фокуса модального окна зависел от новой функции `onClose` при каждом рендере: ввод текста мог переводить фокус на кнопку закрытия. В текущем исходнике A16 использует ref для callback и эффект жизненного цикла окна. Исправление подтверждено исходниками и тестом ввода нескольких символов. Дополнительно PASS: начальный фокус на закрытии, Shift+Tab к последней кнопке, Tab обратно, Escape возвращает фокус исходной кнопке кадра.

В первом мобильном скриншоте один кадр занимал только треть ширины галереи. A16 переключил галерею на одну колонку при ширине до 760px; повторный просмотр `positive-multiple-360.png` подтвердил читаемый полный кадр. Первое full-page изображение окна увеличения содержало артефакт сшивки фиксированного слоя; актуальный viewport-only `evidence-modal.png` подтверждает полное окно и затемнение. Наблюдение теперь 16px, текст/ссылка правила 14px, таймкод кадра 13px; первоначальные замечания закрыты.
